## 1. КАК РАБОТАЕТ GOOGLE ПОИСК

Google полностью автоматизирован. Поисковые роботы (Googlebot) постоянно сканируют интернет, добавляя страницы в индекс. Процесс: **сканирование → индексирование → ранжирование**.

**Важно:** изменения на сайте отражаются в поиске через несколько дней или недель. Не паниковать, если новые статьи не появляются сразу.

## 2. ПРИНЦИПЫ КАЧЕСТВЕННОГО КОНТЕНТА (E-E-A-T)

Google оценивает контент по 4 критериям:
- **E**xperience — личный опыт автора с темой
- **E**xpertise — экспертность, знания
- **A**uthoritativeness — авторитетность источника  
- **T**rustworthiness — достоверность (главный критерий)

### Чек-лист качества контента (самопроверка)

**Содержание и качество:**
- [ ] Есть ли оригинальные факты, исследования, аналитика?
- [ ] Тема раскрыта полно и обстоятельно?
- [ ] Есть ли глубокая аналитика или неочевидные факты?
- [ ] Заголовок информативен и не кликбейтный?
- [ ] Контент хотелось бы сохранить в закладки или поделиться?
- [ ] Нет орфографических и стилистических ошибок?
- [ ] Контент проработан, а не написан в спешке?

**Достоверность:**
- [ ] Источники указаны явно?
- [ ] Автор — эксперт или увлечённый знаток темы?
- [ ] Нет фактических ошибок?

## 3. КОНТЕНТ ДЛЯ ЛЮДЕЙ, А НЕ ДЛЯ ПОИСКОВИКОВ

### Признаки правильного контента ✅
- Ориентирован на конкретную аудиторию с реальной потребностью
- Демонстрирует личный опыт или экспертность автора
- Даёт пользователю достаточно знаний — он не идёт искать дальше
- Понравится посетителю после прочтения

### Признаки плохого контента ❌ (Google не даёт приоритет)
- Контент написан в первую очередь для привлечения трафика из поисковиков
- Много страниц на разные темы в надежде, что хоть что-то попадёт в топ
- Автоматически созданный контент без реальной ценности
- Переписывание чужих материалов без добавления ценности
- Статьи на неинтересные автору темы — только ради SEO
- После чтения у пользователя остаются вопросы
- Дата на странице обновлена без изменения контента

## 4. ПРАВИЛА ЗАГОЛОВКОВ (TITLE)

### Что делать:
- **Уникальный title для каждой страницы** — обязательно
- **Длина**: умеренная — обрезается под ширину экрана (≈50-60 символов)
- **Главное ключевое слово** — ближе к началу
- **Информативность**: точно описывает содержание страницы
- Можно добавлять бренд: `Дигидрокверцетин при диабете — АктивПлюс`

### Что НЕ делать:
- Не использовать слишком общие формулировки ("Главная страница")
- Не перегружать ключевыми словами — это спам
- Не делать одинаковые шаблонные заголовки для всех страниц
- Не использовать кликбейт или преувеличения
- Язык title должен совпадать с языком страницы

### Источники для формирования title (Google автоматически):
- Содержимое тега `<title>`
- Основной видимый заголовок (h1)
- og:title
- Другой заметный текст на странице

---

## 5. ПРАВИЛА META DESCRIPTION

### Что делать:
- **Уникальное описание для каждой страницы**
- Кратко излагать содержание страницы — побуждать к клику
- Включать главный ключевой запрос
- Быть конкретным: факты, ключевые преимущества
- Длина без ограничений, но в результатах поиска обрезается (~150-160 символов)

### Примеры:

❌ Плохо (список ключевых слов):
```
дигидрокверцетин, ДГК, таксифолин, антиоксидант, купить
```

✅ Хорошо (конкретное описание с пользой):
```
Как дигидрокверцетин помогает спортсменам восстановиться после нагрузок. 
Научные данные и практические рекомендации по применению ДГК.
```

❌ Плохо (одинаковое для всех статей):
```
Блог АктивПлюс — всё о дигидрокверцетине и здоровье.
```

✅ Хорошо (специфично для статьи):
```
Разбираем клинические исследования ДГК: как таксифолин защищает 
сосуды и снижает холестерин. Данные российских и зарубежных учёных.
```

## 6. СТРУКТУРА КОНТЕНТА

### Заголовки H2/H3:
- Каждый раздел — свой заголовок
- Порядок заголовков не обязателен для SEO, но важен для удобства чтения
- Нет оптимального количества заголовков — сколько нужно для логики
- Не стоит дублировать title в первом H2

### Структура хорошей статьи:
1. **Вступление** — зачем читать эту статью, что узнает читатель
2. **Основные разделы H2** — каждый раскрывает подтему
3. **Практические советы** — что делать читателю
4. **Вывод** — краткое резюме + мягкий CTA

### Читаемость:
- Короткие абзацы (3-5 предложений)
- Предложения не длиннее 25 слов
- Списки ul/li где уместно
- Blockquote для важных цитат/фактов

---

## 7. КЛЮЧЕВЫЕ СЛОВА — КАК ПРАВИЛЬНО

### Правила:
- Думать как читатель: по каким словам он ищет?
- Учитывать разные формулировки одного запроса
- Использовать синонимы — больше охват при меньшем повторении
- Google понимает смысл запроса, не только точные слова

### Что НЕЛЬЗЯ:
- **Keyword stuffing** — набивание ключевыми словами = нарушение правил Google
- Список ключевых слов без контекста
- Неестественное повторение одних и тех же слов
- Метатег keywords — Google его НЕ использует

### Плотность ключевых слов:
- Нет магической цифры — Google её не использует
- Пишите естественно, не считайте повторения
- Один и тот же запрос — не нужно повторять каждые 2-3 абзаца

---

## 8. УНИКАЛЬНОСТЬ И ОРИГИНАЛЬНОСТЬ

- Не копировать контент с других сайтов целиком или частично
- Не переписывать чужие статьи другими словами (синонимайзинг) — это тоже спам
- Создавать на основе собственных знаний или реальных исследований
- Если факты взяты из источника — добавлять свой анализ, комментарий, контекст
- Дублирование контента на нескольких URL — использовать canonical

---

## 9. ССЫЛКИ

### Внутренние ссылки:
- Используют описательный анкорный текст (не "нажмите здесь")
- Помогают Google находить другие страницы сайта
- Логично связывают тематически близкие страницы

### Внешние ссылки:
- Ссылаться только на достоверные источники
- Если не уверен в источнике — добавить rel="nofollow"
- Пользовательский контент (комментарии) — автоматически nofollow

### Что НЕЛЬЗЯ:
- Покупать или продавать ссылки без nofollow/sponsored
- Спамить ссылками в комментариях
- Схемы обмена ссылками

---

## 10. ПРОДВИЖЕНИЕ САЙТА

Правильные способы:
- Социальные сети
- Взаимодействие с аудиторией
- Email-рассылка (с согласия)
- Сарафанное радио — самый надёжный долгосрочный метод
- Оффлайн: визитки, листовки, упоминание URL

**Важно:** чрезмерное продвижение = обратный эффект. Поисковики могут расценить как попытку манипулировать результатами.

---

## 11. ЧТО НЕ ВЛИЯЕТ НА РАНЖИРОВАНИЕ

- Метатег keywords — НЕ используется Google
- Точная плотность ключевых слов — нет магической цифры
- Минимальный/максимальный объём текста — нет оптимума
- Порядок заголовков H1-H6 — не фактор ранжирования
- E-E-A-T сами по себе — не прямой фактор ранжирования
- Ключевые слова в доменном имени — минимальный эффект
- Субдомен vs подкаталог — несущественно для SEO

## 12. ЧТО GOOGLE ЗАПРЕЩАЕТ (СПАМ)

### Технический спам:
- **Маскировка** — разный контент для Google и пользователей
- **Дорвеи** — страницы созданы только для переадресации
- **Скрытый текст** — белый текст на белом фоне, нулевой шрифт
- **Keyword stuffing** — неестественное набивание ключевыми словами

### Контентный спам:
- **Скрейпинг** — копирование контента с других сайтов
- **Автоматически созданный мусор** — AI-контент без реальной ценности
- **Дублирование контента** — несколько страниц с одинаковым текстом

### Ссылочный спам:
- Покупка/продажа ссылок без nofollow
- Автоматизированное создание ссылок
- Ссылочные фермы и схемы обмена

### Важно для AI-контента:
- Google допускает AI-контент, если он несёт реальную ценность
- AI-контент только для манипуляции поиском — **нарушение правил**
- Рекомендуется указывать, что контент создан с помощью AI

## 13. ТЕХНИЧЕСКИЕ РЕКОМЕНДАЦИИ

### Доступность для Google:
- CSS и JavaScript должны быть доступны Googlebot (не блокировать robots.txt)
- Сайт должен выглядеть одинаково для Google и пользователей
- Проверка через инструмент проверки URL в Search Console

### URL и структура:
- Использовать описательные URL: `/blog/dihydroquercetin-dlya-sportsmenov`
- Группировать тематически схожие страницы в каталоги
- Canonical для дублирующихся страниц

### Sitemap:
- Отправить sitemap в Search Console
- Помогает Google быстрее индексировать новые страницы

### Изображения:
- Описательные имена файлов
- Alt-текст: краткое описание что на изображении
- Размещать рядом с релевантным текстом
- Высокое качество

## 14. ПРИМЕНЕНИЕ ДЛЯ БЛОГА ACTIVEPLUSE.RU

### При генерации каждой статьи:
1. **Тема** — реальная потребность читателя, не просто "SEO-тема"
2. **Исследования** — реальные данные из web_search, не придуманные
3. **Title** — 50-60 символов, главный запрос в начале, уникальный
4. **Description** — 150-160 символов, конкретный, побуждает кликнуть
5. **Структура** — вступление, 3-5 H2-разделов, практика, вывод
6. **Ключевые слова** — естественно, без переспама
7. **Ценность** — после чтения у пользователя не должно остаться вопросов
8. **Уникальность** — не переписывать другие статьи, добавлять свой контекст

### Тональность (важно для E-E-A-T):
- Демонстрировать экспертность в нутрициологии
- Указывать источники ("согласно исследованию...", "по данным...")
- Личный опыт/практика (от лица эксперта-консультанта)
- Достоверность: не обещать то, что не доказано
